# Frontend Design Skill Instructions
[Figma file url](https://www.figma.com/design/ftmlR2G5h3EE9ah9C0Fikf)

Use the Frontend Design plugin for all UI/UX and frontend tasks.

When designing:
- Establish aesthetic direction (style, typography, color, motion).
- Use the Figma MCP server to create or update frames.
- Follow the design system in /design/design-system.md.
- Generate production-ready code when requested.
- Keep designs distinctive, modern, and non-generic.
